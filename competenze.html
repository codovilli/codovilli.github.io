Conoscenze informatiche

Sistemi operativi

Linux (Ubuntu, Debian) e Windows, con esperienza nell'amministrazione di server web (Nginx, Apache, crontab, scripting di shell, gestione risorse e sicurezza).

  • Linux
  • Ubuntu
  • Debian
  • Windows
  • Nginx
  • Apache

Linguaggi e framework

PHP a un ottimo livello, con particolare riferimento alla programmazione avanzata a oggetti, al framework Symfony e ai relativi standard (Composer, autoloading PSR, dependency injection, comandi da console); HTML5, Twig, SCSS, CSS, JavaScript (ES6+), XML, C/C++ e Java; utilizzo del framework frontend UIkit.

  • PHP
  • Symfony
  • Composer
  • Twig
  • HTML5
  • SCSS
  • JavaScript ES6+
  • UIkit
  • C/C++
  • Java

Intelligenza artificiale e strumenti di sviluppo

Utilizzo avanzato di assistenti e strumenti di sviluppo basati sull'intelligenza artificiale (Claude Code) per l'analisi del codice, lo sviluppo e la documentazione; integrazione di endpoint per sistemi RAG (Retrieval-Augmented Generation) e motori di ricerca basati su IA; strumenti di build e prototipazione frontend (Webpack Encore, Vite, Handlebars, Storybook)

  • Claude Code
  • RAG
  • Webpack Encore
  • Vite
  • Handlebars
  • Storybook

DevOps, cloud, sicurezza e reti

Containerizzazione degli ambienti con Docker e Docker Compose; versionamento con Git (GitFlow), deploy automatizzato (Bitbucket Pipelines) e gestione repository su GitHub e Bitbucket; gestione domini, DNS e sicurezza perimetrale tramite Cloudflare (protezione Anti-DDoS, regole WAF personalizzate, filtri anti-bot e gestione crawler IA, Transform Rules per la manipolazione degli header HTTP); cablaggio e amministrazione di reti Ethernet (switch, router, firewall).

  • Docker
  • Docker Compose
  • Git
  • GitHub
  • Bitbucket
  • Bitbucket Pipelines
  • Cloudflare
  • WAF

Piattaforme, CMS ed e-commerce

Pimcore (CMS, PIM e DAM: modellazione DataObject, architetture multi-sito e multilingua, sviluppo areabrick e componenti custom), Magento (realizzazione e manutenzione pluriennale di e-shop B2B con multilingua, listini differenziati e personalizzazione di carrelli, checkout e backend), WordPress, Craft CMS, Sulu.

  • Pimcore
  • Magento
  • WordPress
  • Craft CMS
  • Sulu

Integrazioni, API e servizi

Integrazione di e-commerce con sistemi ERP aziendali (Oracle EBS, Microsoft Dynamics AX) tramite chiamate SOAP / XML e procedure SFTP; gateway di pagamento con carta di credito (Payeezy/First Data, Axerve GestPay, PayPal); integrazione di Google Tag Manager e lead management verso Salesforce.

  • Oracle EBS
  • Microsoft Dynamics AX
  • SOAP / XML
  • PayPal
  • Payeezy
  • Axerve GestPay
  • Google Tag Manager
  • Salesforce

Database e motori di ricerca

MariaDB, MySQL, PostgreSQL (transazioni, viste, trigger) ed Elasticsearch (crawler, definizione indici, normalizzazione dati e reindicizzazione schedulata).

  • MariaDB
  • MySQL
  • PostgreSQL
  • Elasticsearch
